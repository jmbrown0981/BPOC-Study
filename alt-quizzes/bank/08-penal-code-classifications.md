# Chapter 8: Penal Code — Offense Classifications Question Bank

*Straight classification drill: each question names an offense and a circumstance and asks for
the grade (Class C misdemeanor through capital felony), plus a set of defense and affirmative-
defense questions in true/false and multiple-choice form. Built from the offenses summarized in
supplemental/penal-code.html, with every grade checked against the local Penal Code text
(resources/penal_code). Where the summary page and the statute disagree, the statute wins.*

### Q1 — Classification
**LO:** 8.8 · **Source:** PC 15.01(d)

If a person commits criminal attempt of burglary of a habitation (normally a 2nd degree felony), what grade of offense is it?

- [ ] State jail felony
- [x] 3rd degree felony
- [ ] 2nd degree felony
- [ ] 1st degree felony

**Explanation:** PC 15.01(d): criminal attempt is one category lower than the offense attempted, so an attempted 2nd degree felony is a 3rd degree felony.
