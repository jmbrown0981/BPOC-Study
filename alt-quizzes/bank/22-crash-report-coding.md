# Chapter 22: Traffic Code and Crash Investigations — CR-3 Crash Report Coding (LO 22.34) — Question Bank

*Sourced from the Texas Peace Officer's Crash Report Code Sheet (Form CR-3CS, 4/1/2023), the CR-100
"Instructions to Police for Reporting Crashes" manual (2025 Edition), and the CR-80 Vehicle Damage
Guide for Traffic Crash Investigators. This bank covers the CR-3 report's purpose and deadlines, its
classification identifiers, a broad sample of the numbered code lists from the Code Sheet, and the
Vehicle Damage Rating system. Fill-in-the-blank and multiple choice questions are paired so key facts
are tested more than once.*

### Q1 — Fill-in-Blank

person is required by TC 550.062 to forward a crash report to TxDOT not later than the ______ day after
the date of the crash.

- [x] 10th
- [ ] 5th
- [ ] 15th
- [ ] 30th

**Explanation:** TC 550.062 sets a 10-day deadline for forwarding an injury or fatality crash report to
TxDOT.

### Q3 — Concept

An officer investigates a minor crash with no injury and no property damage reaching $1,000. Is

- [ ] No — such crashes may never be submitted to TxDOT under any circumstance

### Q5 — Concept
**LO:** 22.34 · **Source:** CR-100

Besides a later death within 30 days, what other two circumstances require a supplement report to be
submitted to TxDOT?

- [x] If information is later received after an original report was submitted, or if BAC or drug test
      results are later received
- [ ] If the investigating officer is later promoted or reassigned
- [ ] If the crash is later reclassified from a state highway to a county road

**Explanation:** A supplement report is required any time new information comes in after the original

### Q6 — Term ID
**LO:** 22.34 · **Source:** CR-100

**Answer:** Non-Contact Unit

A "______ ______" is a vehicle that contributes to a crash by unusual or illegal behavior but strikes
nothing and suffers neither damage nor injury; it must still be reported with unit and person
information and any contributing factors, the same as if it had made contact.

**Explanation:** A non-contact unit (e.g., a vehicle that swerves and causes a crash without being
struck itself) must still be fully reported, including any factors that contributed to the crash.

### Q7 — Concept
**LO:** 22.34 · **Source:** CR-100

Two vehicles collide, and a few minutes later, a third car plows into the wreckage at the same
location. How should this be reported?

- [x] As two separate crashes on two separate crash reports, since the chain of events was broken by a
      stabilized situation between them
- [ ] As a single chain-reaction crash on one report, since it occurred at the same location
- [ ] As a single crash, but only if all three vehicles are the same body style
- [ ] It should not be reported at all, since only the first collision is reportable

**Explanation:** Chain-reaction crashes are treated as a single crash unless a stabilized situation can
be established between events; a car plowing into an already-stabilized earlier crash scene should be
reported as a separate crash.

### Q12 — Concept
**LO:** 22.34 · **Source:** CR-100

A crash occurs near a school where children are loading onto a school bus, and two other vehicles
collide as a result of the stopped bus — but the school bus itself is never struck and isn't a
non-contact unit. Must the School Bus classification identifier still be selected?

- [x] Yes — the School Bus box must be selected if the crash is related to the presence of a school bus,
      even without the bus itself being a reported unit, with an explanation in the narrative
- [ ] No — the School Bus identifier only applies if the bus itself is a "1-Motor Vehicle" or
      "7-Non-Contact" unit
- [ ] No — this scenario should instead be classified only under MAB
- [ ] Yes, but only if the bus has a seating capacity of nine or more

**Explanation:** The School Bus classification identifier applies both when a school bus is a directly
or indirectly involved unit, and when the crash is merely related to the presence of a school bus (such
as children loading/unloading) — in the latter case, a bus unit is not required, but the narrative must
explain the connection.

A parked trailer is struck by a vehicle, but the trailer was not hitched to any power unit at the time.
