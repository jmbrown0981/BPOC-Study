Property Offender Types Sorting Game

LO 32.7 describes seven types of property offenders: the professional thief, the semi-professional (unskilled) thief, the burglar, the robber, the con artist, the forger / credit card abuser, and the auto thief. Drag (or tap) each characteristic onto the offender type it describes. Penal Code 31.03 (Theft) is left out because the outline lists it under three types. Remember the outline's key point: the “Achilles’ heel” of property crime is disposing of the stolen property.
