Penal Code Offense Sorting Game

Each box is a real Penal Code offense. Drag (or tap) each card onto the offense it belongs to — the required culpable mental state, a base offense level tier, an enhancement (with what it bumps the grade to), or a defense/affirmative defense/doctrine. Some rounds also include the three general boxes: mental-state definitions & doctrine, general defenses & justifications, and cross-cutting Ch.12 punishment enhancements.

How to play: either drag a card straight onto the offense box you think it belongs to, or tap/click a card to pick it up and then tap/click the offense box. Right answer → the card locks into that box (green, with a checkmark — click it to see the statute cite). Wrong answer → the card shakes, the miss is counted, and it goes back to the tray so you can try a different box. Each card is tagged by type (see the legend above) so you know what kind of fact you're sorting. Finish every card in the round to trigger the round-complete banner, then hit New Round for a fresh random deal.
