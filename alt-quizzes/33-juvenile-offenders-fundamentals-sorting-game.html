Juvenile Justice Code Fundamentals Sorting Game

Sixteen boxes, one per statute section — each box is a section of the Juvenile Justice Code and related law, and the cards are that section's first-level subsections to sort back into place. Covers the Code's purpose and definitions, delinquent conduct vs. conduct indicating a need for supervision (Family Code §§51.01–51.03), juvenile jurisdiction, the intoxication offenses that can trigger it (Penal Code §§49.04–49.08, Alcoholic Beverage Code §106.04), a child's waiver of rights and the admissibility of a child's statement (§§51.09, 51.095, CCP art. 38.22, CCP art. 2B.0202 custodial-interrogation recording), guardians ad litem, and the effect of an adjudication or disposition. With 16 boxes the categories default to a collapsed view — expand them as you place cards, or size a round down with Categories/Cards-per-category.
