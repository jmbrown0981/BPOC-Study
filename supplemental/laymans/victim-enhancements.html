TX Penal Code — Victim-Status Enhancements

← Guide Index

Offenses enhanced by victim age (child / under-X), elderly status (65+), or disability — across all chapters. Each card shows the base grade stepping up to the enhanced grade as a color-coded mini-ladder, with the trigger written under the enhanced cell, the same layout as the Illegal Dumping ladder on the Ch.22 Offense & Penalty Reference. Offenses whose enhancement rides on top of a whole value ladder (not a single fixed grade) are called out in prose instead of forced into a two-cell ladder — see the Value Ladders tool for those.
